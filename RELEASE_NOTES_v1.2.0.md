# Better Clock v1.2.0

## New
- **Number styles** - Normal, Flip-clock, LED seven-segment, Retro terminal and an Analog clock face (clock only).
- **Blinking colon** for the clock and timers.
- **Extra text** above and below the numbers, plus optional day name and date lines.
- **Icons** next to the numbers (built-in or your own picture).
- **Picture behind the numbers** (logo or artwork) with opacity and fit options.

- **Move mode** - drag overlays anywhere with the mouse (Ctrl+Alt+M), plus exact X / Y boxes.
- **All monitors** - show an overlay on every monitor at once.
- **Games tab** - each game can have its own looks, switched on automatically while it is running.

All the look options are set separately for the Clock, Timer and Countdown.
