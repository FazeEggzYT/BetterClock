# Better Clock v1.1.0

**Looks, themes and animations.**

## New
- **Per-mode looks and places** - Clock, Timer and Countdown each get their own tab with their own appearance and their own screen position/monitor. Show all three at once if you like.
- **Settings tab** - dark mode, light mode or follow Windows, accent colour, animation speed, UI size, startup options, export/import/reset.
- **Changelog tab** - see what changed in every version.
- **Animated interface** - smooth tabs, switches, buttons, folding cards and theme changes (can be turned off).
- **Show animations** for the overlay: Fade, Slide, Pop.
- **Hide all overlays** key (Ctrl+Alt+H) and optional Timer-only / Countdown-only keys.
- Copy one mode's look to the others, or reset a mode's look.

## Notes
- Your v1.0 settings are carried over.
- Default places: Clock top-centre, Timer top-left, Countdown top-right (change in each tab).
- Start/Stop and Reset keys act on the Timer or Countdown you used last.

Download `BetterClock.exe` below. Windows may warn about an unknown publisher (the file is not code-signed).
