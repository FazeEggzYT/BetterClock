# Better Clock v1.3.0

## New
- **Update inside the app** - Better Clock can download the newest version from GitHub, install it and restart itself. Use the tray menu > Check for updates, or Settings > Updates > Update now.
- Optional automatic updating when Better Clock starts.
- Your settings are kept.

Note: if you are on v1.2.0 or older you need to download this version by hand once. After that, updates install from inside the app.

Windows may warn about an unknown publisher because the file isn't code-signed: click "More info", then "Run anyway".
