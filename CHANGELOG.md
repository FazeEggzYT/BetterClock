# Changelog

## v1.3.1
- Fixed timer not disappearing.

## v1.3.0
- Update from inside the app: download, install and restart by itself (tray menu, Settings > Updates, or automatically at start).

## v1.2.0
- Number styles: Normal, Flip-clock, LED seven-segment, Retro terminal, Analog clock face (clock only).
- Blinking colon option.
- Custom text above / below the numbers, optional day name and date lines.
- Small icon next to the numbers (built-in or your own picture).
- Picture / logo behind the numbers with opacity and fit.
- Drag the overlays with the mouse (Move mode, Ctrl+Alt+M or tray menu), even onto another monitor.
- Exact X / Y position boxes next to the 3x3 grid.
- "All monitors" option, and each overlay can use its own monitor.
- Games tab: per-game looks that switch on while the program is running.
- Update check: tells you when a newer GitHub release exists. Releases are built automatically by GitHub Actions.

## v1.1.0
- New **Changelog** tab (opens by itself the first time after an update).
- New **Settings** tab: dark / light / follow-Windows theme, accent colour, animations on/off + speed, UI size, startup options, export / import / reset.
- **Clock, Timer and Countdown each have their own tab** with their own look (font, colours, background, border, glow, size) AND their own position / monitor. All three can be on screen at once.
- Per-mode show animation (Fade, Slide, Pop, None).
- Animated UI: window open, tab changes, switches, buttons, folding cards, theme fade, moving accent bar.
- "Copy this look to the other modes" and "Reset this look" buttons.
- New key: Hide all overlays (Ctrl+Alt+H). Optional keys that only control the Timer or only the Countdown.
- Bigger live preview with a mini-screen showing where all three overlays sit.
- v1.0 settings are migrated automatically.

## v1.0.0
- First release.
- Clock, Timer and Countdown overlay with their own toggle keys.
- Settings window with tabs (General, Clock, Timer, Countdown, Appearance, Keys, About) and live preview.
- Custom sound for the countdown (mp3, wav, wma, m4a, aac) or a built-in beep.
- 3x3 position grid, monitor choice (game's monitor, primary, or a numbered one).
- Tray icon, start with Windows, loading screen, "Better Clock is running" message.
