# Better Clock v1.4.4 - Each part on its own

## New
- **Every part has its own look:** numbers, label, text above, text below, date, extra lines and icon each get font, size, colour, bold, opacity and left/right/up/down position.
- **Show or hide each part** separately.
- **Order and spacing:** move parts up or down and set the space between them.
- **Progress ring / bar:** own colour and opacity.
- **Icon:** own colour and turn.
- **Copy this section to the other overlays** button on each section.
