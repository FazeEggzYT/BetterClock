# Better Clock v1.4.1.1 - Size controls

## New
- **Overall size** slider is now at the top of every tab (Clock, Timer, Countdown) and goes from 25% up to 500%.
- **Ring size** slider for the progress ring (Timer and Countdown tabs > Progress ring / bar).

## Changed
- The build now accepts four-part version numbers like 1.4.1.1.
