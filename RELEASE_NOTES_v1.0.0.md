## Better Clock v1.0.0

A clock, timer and countdown overlay for games.

**Highlights**
- Clock, Timer and Countdown, each with its own hotkey (all changeable)
- Shows on your game's monitor, in any of 9 positions
- Settings window with tabs and a live preview: fonts, colours, background, border, shadow, size, fade
- Countdown plays your own sound at zero and stays on screen until you hide it
- Tray icon, start with Windows, loading screen

**How to use**
1. Download `BetterClock.exe` and run it.
2. In your game (borderless / windowed-fullscreen), press `Ctrl+Alt+C` for the clock.
3. Right-click the tray icon for settings.

**Notes**
- Games in true exclusive fullscreen can hide overlays. Switch them to borderless.
- Windows may say "unknown publisher" because the file isn't code-signed.
